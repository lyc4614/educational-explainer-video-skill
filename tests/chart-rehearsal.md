# Chart update rehearsal — 2026-10-25

This release was exercised with synthetic inputs. No client manuscript, school
statistics, production images, delivery video or machine-specific paths are
included in the public package.

## Baseline and forward behavior

Two isolated agents received the same synthetic 24-second, six-cue scenario:
three comparable historical thresholds, two differently scoped reported rates,
and an independent count. The baseline read the previous skill; the forward
agent read the candidate skill and required references. Neither was told a
preferred chart selection or given the other's result.

The baseline already rejected an unsupported time-series line and mixed-scope
ranking, kept the independent count separate, and retained the pending-evidence
final gate. Its source/brief checks and 720 integer frame states passed. This is
not evidence of a baseline failure or a measured quality improvement.

The forward exercise produced a source-traceable plan, brief, pure state model
and 21 SVG states. It selected zero-baseline bars, separate single-population
attributed rate drafts, and an independent count card. It passed source/brief
checks, 2,881 integer/fractional state samples and XML parsing of all 21 SVGs.
Underlying unverified claims remained pending; a source-quotation draft did not
clear the final factual gate. Resource hashes and copied-resource agreement were
recorded; a geometry update detected during rehearsal required a refresh and
rerun before the final result was recorded.

These are planning/state/SVG checks. The forward exercise did not render or
visually inspect raster frames, supply missing PNGs, encode video, obtain a new
sample approval, or pass a delivery MP4 gate.

## Component and repository checks

- Geometry tests cover zero baselines, exact historical labels and precision,
  true polyline tracing, fixed sector angles, fractional progress, invalid
  inputs, and partial shares with an explicit whole. A single reported share
  cannot silently become a full ring.
- The copied `ChartLayer.tsx` and adjacent geometry module compiled under strict
  TypeScript with `allowJs` in a local React/Remotion project.
- Six synthetic component cases (bar, line, complete composition, one partial
  rate, zero rate, full rate) rendered at three frames each: 18 full-size stills.
  A contact sheet and four representative full-size frames were visually
  inspected. These stills are not a video playback or mobile-layout guarantee.
- Final repository run: 340 tests, 334 passed, zero failed, six existing
  environment-dependent skips. Skill metadata validation passed.
- On Windows, checkout CRLF conversion initially broke a fingerprinted SRT
  fixture. `.gitattributes` now fixes fixture SRTs to LF; canonical source bytes
  and expected hashes were preserved, and affected tests passed again.

Use these results within their scope. Each real video still requires its own
source checks, semantic layout, timing, visual review and final media gate.
