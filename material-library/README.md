# 教育 3D 可复用素材库

本目录收录 44 项最终原始 PNG：28 个透明主体、16 幅完整场景。2026-10-26 从已归档素材库整理为可迁移的公开副本，PNG 按原字节复制，未重新编码、裁切、加字或改变透明通道。

双击 `index.html` 即可离线查看、搜索和按类型筛选；搜索同时覆盖名称、标签、用途及使用限制。页面内嵌目录，不依赖服务器、网络请求或外部字体。预览可切换深色、浅色和棋盘格背景。

## 文件

| 文件 | 内容 |
| --- | --- |
| `assets/` | 44 张最终 PNG，文件名即素材 ID |
| `catalog.json` | 机器可读目录、原提示词、用途、限制、SHA-256、尺寸、透明比例、可见边界和定位锚点 |
| `generation-records.json` | 44 项生成来源；原始生成提示词；两项鞋面局部编辑的实际提示词、初稿哈希和修正原因 |
| `index.html` | 可直接打开的离线搜索画廊 |

| `build.cjs`、`lib/gallery.cjs` | 仅使用本目录 catalog 重建离线页面，不读取原项目或写入 PNG |
| `verify.cjs` | 使用 Node 内置模块检查目录、相对路径、哈希和离线检索；可选 sharp 像素复检 |
| `verification-report.json` | 此次导出时的逐项原库/公开副本比对记录，保留公开 ID 与哈希 |

`catalog.json` 为第 2 版公开目录结构。每项 `prompt` 与原目录一致；经过局部编辑的两项在原目录中将生成与编辑提示词串接保存。`generationHistory.originalGenerationPrompt` 和 `editPrompts` 将其按实际记录分开保存，未把编辑误记成一次全新生成。初稿未重复收录为新素材，公开文件总数仍为 44 项。

## 语义复用

先按当前脚本的含义选图，再设计停靠位置和数据区。透明主体适合整组平移、缩放、淡入；人物、手臂、椅子和桌面经常固定在同一静态图层，不能由此承诺关节动作、连续书写、眼神追踪或真实 3D 新视角。16 幅完整场景自带深蓝背景。

每项 `cautions` 保留其具体边界。通用校园、宿舍和实验桌不代表任何真实学校配置或教学效果；化学球棍、天平、实验器材仅作概念，不自动成为已核实的分子结构、精密仪器或测量依据；计时器、书本、拼块、分支的数量和姿态不能推断时间、知识点或政策。考前文具包不是官方允许入场清单。

政策、分数、年份、真实校情和科学事实应另查当前来源，再用可编辑文字或图表加入。带字、合成和裁切版本请在各自项目另存，保留本目录 PNG。

## 边界与锚点

坐标以原始 PNG 左上角为原点，单位为像素。

- `transparentFraction`：alpha **恰好为 0** 的像素数除以总像素数；不是视觉主观透明度。
- `bbox`：包含所有 alpha **≥ 16** 像素的最小整数边界，`left/top` 为起点，`width/height` 为跨度。
- `anchor`：可见边界中心，`x = left + width / 2`，`y = top + height / 2`；合成时优先围绕这一锚点定位。

目录尺寸与上述数值来自原归档测量。历史 `inspectionStatus` 和来源记录按原声明保留；此次整理未重复逐图视觉审查，技术校验也不会自动确认内容事实、科学结构、学校情况、政策或版权状态。

## 校验与重建

离线浏览不需要 Node。维护或迁移后，可在此目录运行：

```sh
node verify.cjs
node build.cjs
node verify.cjs
```

基础校验只使用 Node 内置模块，检查目录结构与必要字段、ID/文件唯一性、相对路径与符号链接边界、44 个 PNG 的 SHA-256、生成记录与画廊的一致性，以及名称/ID/标签/分类的实际离线脚本检索。它不是自动内容事实核验，也不重新生成 PNG。

若环境中已通过正常 Node 模块解析提供 `sharp`，可额外运行：

```sh
node verify.cjs --pixels
```

这将实际读取像素并重算尺寸、透明比例和 alpha ≥ 16 的边界。`sharp` 未随库打包；没有该依赖时，基础校验仍可独立运行。像素复检也不能判断人物姿态、仪器结构、政策含义或科学事实。不要为浏览素材而安装依赖或启动服务。
