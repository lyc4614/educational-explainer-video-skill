# 分层教育讲解：可迁移 Remotion 示例

24 秒、1920×1080、30fps、无声。一个透明学习主体先建立，再向左停靠，让右侧的数据关系成为视觉重点。标题、主体、图表、来源提示、字幕分别由代码控制，可单独修改。

**所有图表均为人工合成的演示数据**，不对应真实学校、学生、成绩或政策。柱形、折线、环形是三个独立的语义案例，不能相互推导数字。示例字幕是本次新写的 `input.srt`，没有附带用户原稿。

## 运行

需要 Node.js 22 或更新版本、npm、Remotion 能使用的 Chromium，以及已安装的中文字体（如 Noto Sans SC / Noto Sans CJK SC 或微软雅黑）。安装依赖或首次获取 Chromium 需要网络。本项目固定使用 Remotion **4.0.477**、React 18.3.1；保留合法的 npm 锁文件。Remotion 和 Chromium 适用各自许可，使用前按自己的场景核对；仓库原有 LICENSE 继续适用。

示例使用系统字体；精简Linux/CI环境应先安装中文字体，否则可能出现缺字方框。不同系统字体的字宽可能改变排版，迁移后应重新检查标签、字幕和安全区。

在本目录打开终端，以下命令适用于 Windows、macOS、Linux：

```sh
npm install
npm run dev
```

打开终端显示的 Studio 地址，选择 `LayeredExplainer`。`dev` 不主动打开系统浏览器。停止终端服务后，地址不再可用。Studio 用于预览和代码调整，未实现拖拽式编辑器。

```sh
npm run verify
npm run render
```

`render` 通过显式 `--muted` 输出 `out/layered-explainer.mp4`（H.264、yuv420p、无音轨）；不能仅凭源码没有音频组件就假定导出不含音轨。可用 `npm ci` 按锁文件复现安装。若机器没有可用 Chromium，可先运行 `npx remotion browser ensure`。也可以将自己安装的兼容 Chromium 路径作为 Remotion CLI 的 `--browser-executable` 参数传入；项目源码没有依赖作者电脑的路径。

## 结构与修改入口

| 文件 | 作用 |
| --- | --- |
| `input.srt` | 六条新写合成字幕；`npm run captions` 转为 `src/captions.json` |
| `src/state.mjs` | 24秒状态、主体建立/停靠/退出、合成数据、各图显隐窗口 |
| `src/Explainer.tsx` | 独立图层与数据区布局，字幕和可见来源不烘焙进图片 |
| `src/primitives/` | 从本仓库 `assets/layered-primitives` 和 `assets/chart-primitives` 复用的原组件 |
| `public/assets/student-focus-01.png` | 选定素材的原字节副本 |
| `public/asset-record.json` | 同ID出处、SHA-256、透明边界和使用限制 |
| `tests/state.test.mjs` | 数据关系、图形比例、时间边界、可见主体边界、确定性与退场检查 |

三种图形分别表达：

- 5–10秒：任务A/B/C 的48、64、40分钟，属于同一合成周和计时规则的类别比较，零基线、统一80分钟坐标上限。坐标上限不代表事实中的满分或最大值。
- 10.3–15.7秒：同一虚构任务连续四周的30、45、40、60分钟，观测间隔相同，折线保持第3周下降。类别数据不能改名为年份后直接接成趋势。
- 16–21.7秒：一个虚构清单的完成占比65%，显式 `whole=100`，灰色余环保留未展示部分。没有推算实际总人数、完成数或其他独立比例。

图形按比例展开，标签始终使用精确终值，没有将动画过程中的中间数字伪装成事实。每个图形都在对应字幕开始后出现，完成展开后留出至少2.5秒阅读。最后清空图形与文字，仅保留背景。

## 素材与复用边界

素材 `student-focus-01` 与仓库根目录 `material-library/catalog.json` 中的同ID保持同源；库记录中的出处、完整提示词和生成/检查说明应随库一起保留。示例PNG SHA-256：

```text
602fc1b5e613116924a89621a7085481b30cbd9e08e45568cfd0631618f8080d
```

这是已有透明 **PNG 平面图层**，并非可关节驱动的3D模型。这里使用可见边界 `x=213, y=11, width=813, height=1220` 排位，而非依赖方形画布中心；只做整组平移、等比缩放和淡入淡出。不能由此承诺新视角、连续书写、肢体动作或视线跟随。

换稿时先判断当前来源表达的是类别、真实时间序列还是定义好的整体，再替换数据、单位、精度、范围与来源。不要把本示例的数字或学习主体当成当前来源的证据。字幕改动后运行 `npm run captions`，并同步时间窗口与总长契约。

本目录不包含 `node_modules`、浏览器二进制或作者本机运行时。纯状态测试与类型检查不能替代成片关键帧、真实播放、完整解码和媒体参数验收。
