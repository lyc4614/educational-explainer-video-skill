# 解释设计与品质改进

画面与文案相关，只是起点。素材漂亮、分镜字段完整、视频能完整解码，也不自动证明它解释清楚、动作自然或整片有变化。本指南把这几件事分开检查。详细执行规则见[解释设计规范](../references/explanation-design.md)。

## 先设计解释，再决定用什么素材

每段先写一行：

**文案与时点 → 观众要理解什么 → 对象之间的关系 → 可见动作与前后状态 → 所需主体／姿态／独立图层 → 何时出现结果。**

例如“费用累计”需要看见分项怎样进入账本、哪些费用重复发生、怎样形成总额；“条件转段”需要看见到达节点、等待考核、符合条件才接续。把学校、学生、试卷放在旁边，再让文字解释全部关系，仍然可能只是主题插图。

## 素材要过三道判断

| 判断 | 具体要看什么 | 不足时怎么办 |
| --- | --- | --- |
| 解释能力 | 实际姿态能否完成当前动作？道具能否独立控制？ | 补动作状态、拆层或改用诚实的关系图 |
| 画面品质 | 比例、手部、轮廓、道具结构、材质、光照、透明边缘，在成片大小下是否成立？ | 对照参考局部精修或重做，重新检查实际图像 |
| 连续观看的变化 | 相邻镜头是否反复使用同一人物姿态、校园或左右排版？ | 按新的解释任务调整主体、景别、构图或动作算子 |

复用应同时满足这三点。旧图匹配就保留；缺的是动作、姿态或品质时，就不能因为“库里有图”把缺项抹掉。不固定新图数量，不要求一片用齐素材，也不以换衣服颜色代替动作多样性。

## 从单张主体，走向有目的的动作素材

生成前明确：来源句、动作任务、起止姿态、屏幕尺寸、朝向、接触点、独立部件和光照参考。确实要递交材料，就准备相应手部／文件状态或可用的骨架；确实要改变视角，就准备新视角。整张PNG平移不是行走，缩放不是转身。

同一角色的多个状态应保持身份、比例、服装与光照一致，只补当前镜头需要的状态。拆件无法自然衔接时，改用能解释同一关系的图解，不能假装已有角色关节动画。文字、金额、政策条件始终独立编辑。

如果用户明确要求具体的图像动作主体，不能擅自用图解代替该交付物；表示方式的选择仍须服从当前任务范围。

## 动效先回答“关系怎样变化”

- 累计：分项进入同一账本，保留累计状态，区分一次性与周期性支出。
- 分配：先出现整体，再拆出有依据的份额，最后流向接收对象。
- 比较：保持同一个人或数值，改变其比较环境，显出相对位置。
- 条件：先到检查处，保留等待，再说明满足什么才能继续；两个资格分别检查。
- 定位问题：先展示步骤链，再停在具体出错节点。

入场、推拉、淡入、缓动负责引导注意力。主动作应能让观众看到关系的变化，避免整片只剩“人物＋卡片＋连线”或把所有关系都做成闸门。

## 验收从单帧扩大到连续观看

先看开篇几个不同时点：观众获得的信息是否在推进，还是同一张海报只换字幕？再看相邻镜头接触表，找人物、姿态、构图和动作方式的重复。最后连续播放实际导出的视频，检查准备、动作、落位、阅读停留和承接。

暂时隐藏解释卡片，看主体动作还能否表现比较、累计或条件；随后恢复文字，检查概念、单位和限定条件。这是诊断方法，不要求每个概念脱离文字也能完全理解，也不强制每几秒切镜。

分别记录：**解释是否清楚、素材品质是否成立、动作节奏是否可读、媒体技术是否正确**。任何一项通过，都不能替其他项盖章。

## 下一轮怎么验证

优先选择少量有代表性的真实段落，验证精修主体、角色动作状态和关系动画。已有制作实践支持“先拆解释、随语义推进构图”能改善观看反馈；更精细的素材、多状态角色及其对理解的提升，仍需实际图像和短片验证。不要把文档完善、计划演练或更多测试数写成这些效果已经达成。
